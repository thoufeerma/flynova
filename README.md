# Flynova Reisen LLP — Luxury Bespoke Travel & Temple Pilgrimage Platform

Flynova Reisen LLP is an ultra-luxury travel concierge and pilgrimage specialist platform founded in Ernakulam, Kerala. The website delivers bespoke South and North Indian temple yatra circuits, premium chauffeur-driven itineraries, luxury 3D interactive mapping of Kerala, and high-touch concierge booking.

## Key Features

- **Hero Experience**: Auto-advancing luxury hero slideshow with smooth horizontal transitions, typography, and interactive search bar.
- **Divine Temple & Heritage Tour Packages**: Over 28+ handpicked pilgrimage itineraries across Tamil Nadu, Kerala, Karnataka, Andhra Pradesh, and North India.
- **3D Interactive Kerala Map**: Three.js/WebGL interactive district-by-district exploration with smooth animated dossiers for all 14 districts of Kerala.
- **Dynamic Package Detail Pages (`/package/[id]`)**: Full multi-day itineraries, sacred theertham/darshan breakdowns, hotel tier selections (Comfort, Heritage, Royal VIP), FAQs, and 1-click WhatsApp concierge integration.
- **Interactive Trip Planner**: Tailored quotation modal pre-filled with chosen package and travel dates.
- **Bespoke Luxury Positioning**: Privacy-focused custom quotations on request, without overt price tags.
- **Luxury Loading Screen**: Custom animated Flynova Reisen crest loader.

## Tech Stack

- **Framework**: Next.js 16 (Turbopack, App Router)
- **Styling**: Tailwind CSS & Vanilla CSS
- **3D Graphics**: Three.js & React Three Fiber
- **Icons**: Lucide React
- **Animations**: CSS keyframes & cubic-bezier transitions

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
npm run build
npm run start
```
